# DREAMS

App pessoal para guardar PDFs dos seus projetos de sonho.

1. Ative o GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).
2. Abra o link no Chrome do celular.
3. Menu (três pontos) > Adicionar à tela inicial / Instalar app.

Os PDFs ficam salvos no navegador do próprio celular.
